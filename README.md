# Auspify — Responsive Landing Page

A responsive landing page built from the provided task brief.

## Features
- Responsive navigation bar with mobile hamburger menu
- Hero section with CTA buttons
- Product/dashboard visual created with HTML/CSS/SVG
- Feature cards
- About section
- Contact CTA
- Responsive desktop/tablet/mobile layouts
- Semantic HTML and accessible button/navigation labels

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
No build tool is required.

1. Open `index.html` directly in a browser, or
2. Use VS Code Live Server.

## Project structure
```text
auspify-responsive-landing-page/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Customize
Edit the text in `index.html` and colors/spacing in `style.css`.
